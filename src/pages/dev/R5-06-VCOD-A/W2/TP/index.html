Système de gestion de formations

Les employés souhaitant suivre des formations peuvent consulter un catalogue de formations et faire une demande. La demande est traitée par un responsable de l’entreprise, qui peut consulter le dossier RH de l’employé et le contenu de la formation pour prendre sa décision. Le catalogue de formations est proposé et maintenu par un prestataire extérieur. Employés et responsables disposent d’un client spécifique pour, respectivement, formuler et valider une demande. Le client utilise l'intranet de l'entreprise pour authentifier ses utilisateurs, ainsi que pour récupérer les dossiers RH.

  2. Identifiez les différents composants de chaque client/serveur.
  3. Ajoutez les liens entre les différents éléments du diagramme.

Site de vente en ligne

Un site de vente en ligne permet de visualiser un catalogue de produits, les ajouter à un panier, de passer commande, puis de suivre ses commandes. Lors de la création d'une commande à partir du panier :
  1. la disponibilité des produits sont vérifiées auprès du fournisseur.
  2. le payement est effectué auprès de la banque.
  3. fournisseur et transporteur sont notifiés de la commande.
Les bases de données utilisateurs, produits, ainsi que commandes sont hébergées sur un serveur dédié.

Démineur

Le démineur est un jeu dont le but est de trouver le plus rapidement possible toutes les cases du plateau contenant des mines sans les toucher.
Le jeu est composé d’un plateau rectangulaire, d’un chronomètre et d’un compteur de mines. Le plateau est un quadrillage de cases. Au début du jeu, toutes les cases du plateau sont couvertes, le compteur de mines indiquant le nombre de mines restant à localiser. Le chronomètre compte le nombre de secondes écoulées depuis le début de la partie. La partie commence lorsque la première case est découverte. Le joueur peut interagir en découvrant une case, ou en la marquant d’un symbole (sans influence sur le déroulement du jeu).
L'application comporte aussi un menu permettant d'enregistrer, de charger, ou de générer une partie.

    • : permet d'encoder/décoder une partie.
  4. Reliez chaque élément graphique du jeu aux interfaces dont ils dépendent.

Télécommande

À la réception d'un signal infrarouge, le capteur infrarouge de la télévision décode le signal afin de le transformer en commande. La commande est ensuite transférée au composant concerné.

Pour rappel : Une télécommande permet de contrôler un téléviseur. Ce téléviseur possède des hauts parleurs, un mécanisme de mise sous tension (alimentation), un mécanisme de changement de de chaîne (turner), un mécanisme de réglage du son par augmentation ou diminution (ampli), un écran associé à un mécanisme de réglage du contraste et de la couleur des images par augmentation ou diminution.

Distributeur de billets automatique

Lorsqu'un utilisateur souhaite retirer de l'argent, il insère sa carte bancaire dans le DAB, puis demande à retirer un montant. Le DAB vérifie d'abord auprès du module de distribution de billets si le montant demande est disponible, avant de demander le code PIN à utilisateur.
Le DAB vérifie le code PIN saisi auprès de la carte bancaire. En cas de 5 tentatives infructueuses, la carte est avalée. Si le code PIN est correct, le DAB transmet la demande de retrait à la banque.
Quoi qu'il arrive, la carte est éjectée. Si la carte n'est pas prise au-delà d'un certain temps, la carte est avalée.
Le module de distribution de billets sort ensuite les billets. Idem, si les billets ne sont pas pris au-delà d'un certain temps, ils sont avalés. Si tout se passe bien, le retrait est confirmé auprès de la banque.

Gestion des emprunts

Lorsqu'un utilisateur souhaite emprunter un livre, le système interroge tout d'abord la base de données afin de vérifier s'il peut emprunter. Il vérifie ensuite auprès de la base de données s'il est disponible.
Si le livre n'est pas disponible, le système demande à l'utilisateur s'il souhaite le réserver. Il notifie ensuite les différentes bases de données afin d'enregistrer l'emprunt ou la réservation.

Entreprise (à supprimer?)

L'entreprise Poule Emploi propose un service de mise en relation entre employeurs potentiels et demandeurs d'emplois, permettant à l'un comme l'autre de consulter un catalogue (d'offres ou de CV). L'accès à ces catalogues, ainsi que l'ajout d'une offre ou d'un CV, nécessite un compte client payant créé par un employé de l'entreprise Poule Emploi. Le management a accès aux données client pour des raisons de reporting.
