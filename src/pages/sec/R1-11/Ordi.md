
<h3>Le poste de travail</h3>

<div>Les postes de travail sont les ordinateurs sur lesquelles vous travaillez, ils possèdent :
<ul>
    <li><b>un processeur</b> (CPU) : exécute des instructions ;</li>
    <li><b>une puce ou carte graphique</b> (GPU) : gère l'affichage ;</li>
    <li><b>une mémoire vive</b> (RAM) : stocke des données temporaires ;</li>
    <li><b>des supports de stockages</b> (e.g. SSD) : sur lesquels sont enregistrés des fichiers ;</li>
    <li><b>une puce ou carte réseau</b> : gère le WiFi, Bluetooth, et Ethernet.</li>
</ul></div>

<div>La <b>carte mère</b> relie ces différents composants et fourni des ports permettant de brancher des <b>périphériques</b> (<i>devices</i>) :
<ul>
    <li><b>USB</b> : pour les claviers, souris, disques externes, etc.</li>
    <li><b>RJ45</b> : pour les câbles Ethernet.</li>
    <li><b>HDMI/Display Port/VGA</b> : pour les écrans.</li>
</ul></div>

<p>Tous ces composants matériels sont gérés par le <b>Système d'exploitation</b> (<i>Operating System</i>), e.g. Windows, Linux, etc.</p>
